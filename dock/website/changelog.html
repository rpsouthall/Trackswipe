Changelog

Recent improvements, fixes, and feature work for the Anchor app.

All notable changes to Anchor are documented here. This page highlights the most recent notes from the project changelog.

v1.2.5

About-page feedback and support improvements.

Changed

  • About links are easier to find. The About page now groups Microsoft Store ratings, GitHub stars, feedback, and issue reporting under Feedback & support, with a dedicated section icon.
  • License, privacy policy, website, and changelog links are grouped together, and the source-code link has been removed.

v1.2.4

Added and fixed in the latest release.

Added

  • Group icon colour. A group's editor now includes a Colour row, with the theme colour, Windows palette presets, and a custom swatch picker. The chosen colour is stored on the item as IconColor and is drawn on the dock strip, drag ghost, and Apps & links settings list.
  • Colour-only tinting is respected without overriding the icon itself, and the accent is ignored when Windows High Contrast is active.

Fixed

  • Taskbar icon issue in the Store build. The app icon previously appeared on a blue square in the taskbar, desktop, and Start menu. The package now includes the correct unplated icon variants, so Windows draws the transparent artwork cleanly.

v1.2.3

Drag-and-drop improvements and crash/hang hardening.

Added

  • Drop anything onto Add to Dock. Apps, files, folders, shortcut links, and web links can now be dropped directly into the Add window, where Anchor fills the form and adds the item in one step.
  • Drag 'n drop support was expanded with a dedicated drop zone and grouped multi-item handling.
  • The dock now has a smoother drag-and-drop experience, including a drop shell that reveals the destination slot before the item lands.

Changed

  • Type tiles were consolidated into a more compact layout for cleaner visual balance.
  • Web URL normalization logic was made consistent between the dock strip and Add item window.

Fixed

  • Multiple crash and hang bugs were fixed during the hardening pass, including configuration loss, unhandled null items, unclosed drag timers, slow folder scans, and leak-prone Settings windows.
  • Power-user flows like shortcut resolution, app startup, and background polling were made more resilient.

Store build

The recommended install path is the Microsoft Store, which keeps Anchor updated automatically and keeps the app in the supported packaging flow.

Open-source

Anchor is still developed in the open on GitHub, with release notes and issue reporting available alongside the source code.

Privacy

Anchor stays local-first, with no account, analytics, or tracking system. The app stores your dock settings in your user profile.
